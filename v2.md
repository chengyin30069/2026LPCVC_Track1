# ViT-H-14 + CC3M (CLIP-KD script) Training Commands

```bash
cd /home/lpcv2026/2026LPCVC_Track1
conda activate lpcv
```

## 1) Prepare CC3M with CLIP-KD `gather_cc.py`

```bash
mkdir -p raw_datasets/cc3m raw_datasets
cd raw_datasets
[ -d CLIP-KD ] || git clone https://github.com/winycg/CLIP-KD.git
cd /home/lpcv2026/2026LPCVC_Track1/raw_datasets/cc3m
```

Download CC3M URL TSV files directly to expected names (already handled if you ran this once):

```bash
cd /home/lpcv2026/2026LPCVC_Track1/raw_datasets/cc3m
curl -L --fail --retry 5 --retry-delay 3 \
  -o cc3m_train.tsv \
  https://media.githubusercontent.com/media/ryan-warner/ML-Project/e8605e3a9bde521e8610b62b147d0e6045c0f18b/dataset/Train_GCC-training.tsv
curl -L --fail --retry 5 --retry-delay 3 \
  -o cc3m_val.tsv \
  https://raw.githubusercontent.com/ryan-warner/ML-Project/e8605e3a9bde521e8610b62b147d0e6045c0f18b/dataset/Validation_GCC-1.1.0-Validation.tsv
wc -l cc3m_train.tsv cc3m_val.tsv
```

Run upstream downloader (this step performs image downloading):

```bash
cd /home/lpcv2026/2026LPCVC_Track1/raw_datasets/CLIP-KD
python src/data/gather_cc.py \
  /home/lpcv2026/2026LPCVC_Track1/raw_datasets/cc3m/images \
  /home/lpcv2026/2026LPCVC_Track1/raw_datasets/cc3m/cc3m_train.tsv \
  /home/lpcv2026/2026LPCVC_Track1/raw_datasets/cc3m/cc3m_val.tsv
```

## 2) Convert CC3M CSV to this repo format

```bash
cd /home/lpcv2026/2026LPCVC_Track1
python prepare_cc3m_track1_dataset.py \
  --cc3m-train-csv raw_datasets/cc3m/cc3m_train.csv \
  --cc3m-image-root raw_datasets/cc3m/images \
  --output-dir dataset_cc3m \
  --max-pairs 2890000 \
  --link-mode symlink \
  --overwrite
```

## 3) Cache embeddings with new teacher: `laion/CLIP-ViT-H-14-laion2B-s32B-b79K`

```bash
cd /home/lpcv2026/2026LPCVC_Track1
python precompute_teacher_embeddings.py \
  --model-id "hf-hub:laion/CLIP-ViT-H-14-laion2B-s32B-b79K" \
  --backend open_clip \
  --img-list dataset_cc3m/img_list.csv \
  --image-folder dataset_cc3m/images \
  --batch-size 32 \
  --output artifacts/teacher_image_embeddings_h14_cc3m.npz \
  --output-dtype float16 \
  --channels-last \
  --device cuda:0
```

## 4) Train (CLIP-KD-style, 3090Ti-safe, no early-stop kill surprise)

```bash
cd /home/lpcv2026/2026LPCVC_Track1
python train_student_distill.py \
  --clipkd-preset clipkd-upstream-h14 \
  --img-list dataset_cc3m/img_list.csv \
  --image-folder dataset_cc3m/images \
  --teacher-embeddings artifacts/teacher_image_embeddings_h14_cc3m.npz \
  --text-embeddings artifacts/text_embeddings_student_b16_cc3m.npz \
  --teacher-text-embeddings artifacts/text_embeddings_teacher_h14_cc3m.npz \
  --output-dir artifacts/student-h14-cc3m-CLIPKD \
  --num-workers 8 \
  --prefetch-factor 4 \
  --pin-memory \
  --channels-last \
  --save-epoch-checkpoints \
  --device cuda:0
```

## 5) Resume training from a saved epoch

```bash

  --num-workers 2 \
  --prefetch-factor 2 \
  --pin-memory \
  --channels-last \
  --save-epoch-checkpoints \
  --device cuda:0
```
